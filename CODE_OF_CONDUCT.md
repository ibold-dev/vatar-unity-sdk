# Code of Conduct

## Our commitment

We commit to a welcoming, respectful, and harassment-free community for everyone who participates in this project.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on ideas and code, not people.
- Respect differing experiences and viewpoints.
- Report security issues privately through the process in [SECURITY.md](SECURITY.md).

## Unacceptable behavior

Harassment, discrimination, threats, sexualized language or imagery, doxxing, and sustained disruption are unacceptable.

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict participation when this code is violated. Report concerns to [support@lagoslife.app](mailto:support@lagoslife.app) with the subject `Community conduct`.
